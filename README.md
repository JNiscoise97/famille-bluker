# Famille Bluker

Rapports de généalogie sur Philibert BLUKER (1840–1912) et Vitaline INDIANA (1855–1894), à Saint-Leu (La Réunion), et leurs descendants — préparés pour Corine, Marie et Chloé.

Trois pages HTML autonomes (aucune dépendance externe à part les polices Google Fonts) :

- **`famille_bluker.html`** — le rapport principal, en 7 pages avec navigation par onglets : le lien entre les trois, les ascendants de Philibert et de Vitaline (fratries, mariages, recensements d'esclaves), la descendance complète sur plusieurs générations, et le détail de chaque branche (Corine, Marie, Chloé) avec tous les mariages. Photos de famille intégrées, cliquables en plein écran.
- **`rapport_bluker.html`** — la première version, en une seule page longue.
- **`audio_explication.html`** — une page qui lit à voix haute (synthèse vocale du navigateur) l'explication du lien entre les trois branches.

Le dossier `photos/` contient les photos de famille utilisées (`photos/optimized/` = versions compressées effectivement intégrées dans `famille_bluker.html`).

Ouvrir n'importe lequel des fichiers `.html` directement dans un navigateur — aucun serveur nécessaire.
